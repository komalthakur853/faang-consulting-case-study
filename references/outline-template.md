# Canonical Outline (use exactly)

## About the Client
- Who they are (public name or rich anonymous descriptor)
- Industry, scale, geography, key constraint that made the problem acute
- Why this problem mattered now

## Top 3 Achievements
- Bullet 1 — quantified (before → after + instrument/window)
- Bullet 2 — quantified
- Bullet 3 — quantified
(Keep to three. Rank by reader impact.)

## Technical Problems
- Problem 1 (symptom + root cause + business cost)
- Problem 2
- Problem 3 (or fewer if only two were material)
Keep this section crisp. Engineers should nod.

## Solutions
For each major decision:
- Context / constraint
- Options considered (at least two)
- Decision + why it won
- Implementation highlights (architecture, key tech, migration approach)
- Measured outcome

End with a short **Limitations & residual risks** paragraph.

## Business Solution / Impact
- How the technical work translated into business outcomes
- Time-to-value, cost, revenue, risk, team velocity, or strategic optionality
- Any second-order effects worth noting

## Testimonial
- One strong, specific quote (or anonymized equivalent)
- Attribution (role + company descriptor if private)
