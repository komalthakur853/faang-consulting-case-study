# Anonymization Ladder (for private companies)

Apply the highest level of specificity that still protects the customer.

1. **Full public** (only for public companies)
2. **Named private with permission** (rare — requires explicit written approval)
3. **Rich descriptor** (default for private)
   - Industry + stage + scale + geography + distinctive constraint
   - Example: “a Series B European payments infrastructure company processing €4B annual volume”
4. **Industry + scale only**
   - “a mid-market US healthcare SaaS platform”
5. **Purely generic**
   - “a high-growth B2B SaaS company”
6. **Fictional name** (only if user requests)
   - Clearly label as fictional (“Northwind Logistics (fictionalized)”)

Never invent unique identifiers, product names, or founder details for private companies.
